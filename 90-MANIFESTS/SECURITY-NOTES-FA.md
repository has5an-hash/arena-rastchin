# ملاحظات امنیتی انتقال

- Repository طبق تصمیم صریح مالک Public است. بنابراین هر فایل دارای secret، salt، credential، token، داده شخصی یا لاگ حساس باید قبل از Push حذف یا sanitize شود.
- `nail.zip` اصلی دارای `wp-config.php` توسعه‌ای و saltهای واقعی محیط محلی بود. برای نسخه قابل انتقال، saltها با placeholder جایگزین شده‌اند.
- نسخه‌های اصل حساس عمداً روی GitHub عمومی قرار نمی‌گیرند.
- دیتابیس‌های بیوتیا قبل از انتشار عمومی باید از نظر credential، حساب تست، ایمیل، توکن، رزرو و داده شخصی sanitize شوند.
- هر secret/API key/token جدید باید خارج از Git و در secret manager یا متغیر محیطی نگهداری شود.
