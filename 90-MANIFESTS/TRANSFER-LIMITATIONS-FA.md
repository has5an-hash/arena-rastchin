# محدودیت‌های واقعی این انتقال

1. مخزن `has5an-hash/arena-rastchin` توسط مالک ساخته شده و اتصال GitHub این نشست دسترسی Admin/Push به آن دارد. Repository طبق تصمیم مالک Public است.
2. File Library امکان جستجو/خواندن برخی فایل‌های قبلی را داد اما برای بعضی فایل‌های باینری قبلی مسیر Mount قابل انتقال ارائه نکرد؛ بنابراین فایل‌های مفقود بازسازی جعلی نشده‌اند.
3. فایل‌های بیش از محدودیت عادی GitHub باید با Git LFS یا یک روش Large File مناسب sync شوند.
4. هیچ نسخه اصل دارای Salt/credential محلی به Repository عمومی Push نمی‌شود.
