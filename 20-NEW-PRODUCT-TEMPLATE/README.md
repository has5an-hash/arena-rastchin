# قالب شروع محصول جدید برای Arena

این پوشه الگوی ساخت محصول جدید برای فروش در راست‌چین است.

## ترتیب کار
1. `PRODUCT-BRIEF.md` را با واقعیت محصول پر کن.
2. قبل از توسعه، منابع رسمی راست‌چین و قوانین زنده مرتبط را بررسی کن.
3. معماری و وابستگی‌ها را مشخص کن؛ قابلیت اصلی تا حد ممکن وابسته به افزونه/سرویس پولی نباشد.
4. توسعه را با WordPress Standards، Security، RTL/Persian، Responsive و Performance جلو ببر.
5. بعد از هر تغییر مادی Work Log/Checkpoint را نگه دار.
6. `QA-GATE.md` را واقعاً اجرا کن.
7. فقط پس از پاس کامل Gate، `RELEASE-CHECKLIST.md` را انجام بده.

## ساختار پیشنهادی محصول
- `source/` — سورس واقعی
- `docs/` — معماری، راهنما، changelog، handoff
- `qa/` — گزارش تست‌ها و شواهد
- `release/` — فقط خروجی‌های پاک و قابل‌تحویل
- `marketplace/` — متن/تصاویر/مشخصات فروش پس از تأیید واقعی قابلیت‌ها

هیچ credential، داده شخصی، cache، log، backup یا فایل تست غیرضروری وارد Release نشود.
