Core booking, content types, Elementor Free widgets and portable demo packages for Beautia.

== Installation ==
1. Install and activate the Beautia theme.
2. Install and activate beautia-core.zip.
3. Open Beautia > Demo Importer, or Beautia > Core Demo Packages to upload a portable demo ZIP.
