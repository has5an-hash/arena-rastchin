# تاریخچه تغییرات — بیوتیا (Beautia)

## نسخه ۴.۰.۰ — وضعیت تجاری ثبت‌شده در مرجع

- معماری استاندارد قالب + افزونه Beautia Core و بسته‌های مستقل Core Demo.
- افزایش ویجت‌های Elementor Free از ۱۹ به ۳۵؛ بدون نیاز به Elementor Pro.
- مرکز کنترل فارسی ظاهر و محتوا، ترتیب/نمایش سکشن‌های هر دمو، مگامنوی بومی و تنظیمات سرعت/تصویر.
- هفت هویت مستقل، پیشنهاد خدمت، دفتر الهام و تقویم زنده وقت‌های آزاد.
- گفت‌وگوی زنده بومی، اتصال اختیاری واتساپ/تلگرام و بهینه‌سازی دارایی‌ها.
- اصلاحات فارسی/RTL، تقویم شمسی، رزرو، OTP، پیامک و دسترس‌پذیری.

## مسیر نسخه‌ها

مرجع تاریخی پروژه نسخه‌های 1.0.0 تا 4.0.0 را ثبت کرده است. برای تصمیم انتشار، به وضعیت واقعی کد، QA و Gate نهایی تکیه شود و صرف وجود این Changelog به معنی آماده‌بودن Release نیست.
