فوکوس، بستن با Esc و

بخش‌های تازه صفحه اصلی: **درباره ما با کلاژ تصویر و چک‌لیست**، **«چطور کار می‌کند»

## ۴. جلوه‌ها و انیمیشن‌ها

ظاهر شدن هنگام اسکرول (IntersectionObserver)، تفکیک حرف‌به‌حرف تیترها، شمارنده‌های
متحرک، لایه‌های پارالاکس، کارت‌های سه‌بعدی تیلت، نشانگر موس مغناطیسی، نوارهای
مارکی، دانه‌بندی فیلم، پیش‌لودر، فیلتر نمونه‌کارها، اسلایدر لمسی با نقطه و پخش
خودکار، اسلایدر مقایسه قبل/بعد، لایت‌باکس و نوار رزرو چسبان موبایل.

همه با **جاوااسکریپت خالص، حدود ۲۰ کیلوبایت، بدون jQuery** و با احترام کامل به
`prefers-reduced-motion`.

## ۵. نصب

۱. فایل `beautia.zip` را از مسیر **نمایش → پوسته‌ها → افزودن → بارگذاری پوسته** آپلود کنید.
۲. فعال کنید. قالب جدول‌های پایگاه داده و برگه‌های «رزرو نوبت»، «پنل کاربری» و
   «ورود» را خودکار می‌سازد.
۳. به **بیوتیا → نصب دموی آماده** بروید؛ یا ZIP مستقل دمو را از **بیوتیا → بسته‌های دموی Core** بارگذاری و سپس وارد کنید.
۴. به **بیوتیا → درگاه پیامک** بروید، سرویس‌دهنده را انتخاب و کلید API را وارد کنید و
   دکمه *ارسال پیامک آزمایشی* را بزنید. (در زمان توسعه روی حالت «فقط لاگ» بماند.)
۵. **بیوتیا → تنظیمات رزرو** را تنظیم کنید: ساعت کاری، گام زمانی، حداقل فاصله،
   بازه لغو، نوع تقویم، واحد پول، جهت نوشتار و ارقام فارسی.

## ۷. قلاب‌های توسعه‌دهنده

```php
// استفاده از درگاه پیامک اختصاصی خودتان
add_filter( 'beautia_pre_send_sms', function ( $null, $mobile, $text, $event, $vars ) {
    my_gateway_send( $mobile, $text );
    return true; // بازگرداندن مقدار غیر null، درگاه‌های داخلی را متوقف می‌کند
}, 10, 5 );

// واکنش به رویدادهای رزرو
add_action( 'beautia_booking_created', function ( $id ) { /* … */ } );
add_action( 'beautia_booking_status_changed', function ( $id, $new, $old ) { /* … */ }, 10, 3 );
add_action( 'beautia_user_registered', function ( $user_id, $mobile ) { /* … */ }, 10, 2 );

// افزودن یک اسکین دموی تازه
add_filter( 'beautia_demos', function ( $demos ) {
    $demos['tattoo'] = array( 'label' => 'استودیو تتو', 'accent' => '#2E4057', 'accent2' => '#C9A227', 'desc' => '' );
    return $demos;
} );
```

جدول‌های پایگاه داده: `{prefix}beautia_appointments` و `{prefix}beautia_appointment_log`.

## ۸. پیش‌نمایش

پوشه `/preview` یک نمایش ایستا و کاملاً قابل کلیک از **هر هفت دمو** است که
**همان CSS و JS واقعی قالب** را بارگذاری می‌کند. اجرا:

```bash
python3 -m http.server 3000 --directory preview
```

در پیش‌نمایش، لایه پیامک شبیه‌سازی شده است و کد تأیید همیشه **۱۲۳۴۵** است.
