# خلاصه مرجع راهنمای کاربر زرپالس

منبع این فایل راهنمای رسمی کاربر زرپالس نسخه 1.0.0 و Readme نسخه 1.0.1 پروژه است. Arena باید برای وضعیت نهایی قابلیت‌ها کد/نسخه جاری و QA را هم بررسی کند.

## کار اصلی افزونه
زرپالس برای فروشگاه‌های طلا، جواهر و سکه در WooCommerce طراحی شده و گردش‌کار «دریافت نرخ پایه → اعمال فرمول → بروزرسانی قیمت محصول → رزرو زمان‌دار قیمت در سبد» را مدیریت می‌کند.

## نیازمندی‌های ثبت‌شده
- WordPress 6.2+
- WooCommerce 7.5+
- PHP 7.4+
- برای بروزرسانی منظم در سایت کم‌ترافیک، Cron واقعی سرور پیشنهاد/توصیه شده است.

## منابع نرخ
سه مسیر اصلی در راهنما ثبت شده است:
- محاسبه هوشمند و خودکار
- دریافت نرخ مرجع اتحادیه
- API مستقیم/دستی

API مستقیم می‌تواند URL، متد، نوع پاسخ، پارامترها و مسیر داده را بگیرد. برای شاخص‌های 18k، 24k، مظنه، سکه امامی، نیم‌سکه و ربع‌سکه مسیرهای فروش به مشتری و خرید از مشتری می‌توانند مستقل باشند. تست اتصال قبل از اتکا به منبع ضروری است.

## Cron واقعی
راهنما توضیح می‌دهد WP-Cron به بازدید وابسته است و برای فروشگاه نرخ‌محور ممکن است تأخیر داشته باشد. زرپالس آدرس Cron اختصاصی دارای توکن ارائه می‌کند و راهنما اجرای یک‌دقیقه‌ای روی هاست و کنترل `DISABLE_WP_CRON` را توضیح می‌دهد. توکن Cron محرمانه است و نباید در Repo، تصویر عمومی یا تیکت عمومی منتشر شود.

## فرمول قیمت
موتور فرمول فقط متغیرهای مجاز، اعداد، پرانتز و عملگرهای ریاضی را می‌پذیرد و نباید کد PHP/JavaScript دلخواه اجرا کند. فرمول‌های وابسته به محصول/پروفایل تا رفع وابستگی نباید کورکورانه غیرفعال شوند.

## قیمت‌گذاری محصول
در تب قیمت‌گذاری طلا، مدیر می‌تواند فعال/غیرفعال بودن قیمت هوشمند، نوع محصول، نرخ پایه، وزن، عیار، اجرت، سود، مالیات و هزینه‌های جانبی را مطابق گزینه‌های واقعی نسخه جاری تنظیم کند. قبل از فعال‌سازی گسترده باید یک محصول آزمایشی و Preview قیمت بررسی شود.

## شورت‌کدهای ثبت‌شده در Readme 1.0.1
- `[zarpulse_prices ...]`
- `[zarpulse_price ...]`
- `[zarpulse_card ...]`
- `[zarpulse_ticker ...]`
- `[zarpulse_price_updated ...]`
- `[zarpulse_price_lock_timer]`
- Aliasها برای 18k، 24k، mazaneh، coin، nim و rob

## امنیت ثبت‌شده در Readme
- درخواست مدیریتی حساس باید capability و nonce داشته باشد.
- ورودی‌ها sanitize/validate و خروجی‌ها escape شوند.
- مقصد API مستقیم باید معتبر و طبق سیاست نسخه جاری کنترل شود.
- توکن API به‌شکل امن ذخیره شود.
- فرمول‌ها فقط از grammar مجاز استفاده کنند.

## نسخه 1.0.1
Readme نسخه 1.0.1 رفع توقف طولانی هنگام ذخیره منابع، انتقال بروزرسانی نرخ/همگام‌سازی محصول به پردازش پس‌زمینه و Batch و محدودسازی زمان/تلاش‌های شبکه را ثبت می‌کند.

## قانون Arena
این سند راهنمای دانش است، نه مدرک QA نهایی. برای هر ادعای فروش، سازگاری یا انتشار، سورس جاری `source-repo`، تست واقعی و مرجع اصلی پروژه را بررسی کن.
