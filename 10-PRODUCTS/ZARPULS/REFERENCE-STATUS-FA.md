# زرپالس — وضعیت مرجع انتقال

- مرجع اصلی تصمیم‌ها: چت `وضعیت نهایی افزونه زرپالس`.
- محصول: افزونه WooCommerce برای قیمت‌گذاری طلا، جواهر و سکه.
- فایل Readme شناخته‌شده در File Library نسخه 1.0.1 را اعلام می‌کند.
- فایل اصلی `zarpuls.php` در File Library نسخه محافظت‌شده/ionCube مربوط به راست‌چین است؛ در این انتقال از بازسازی ناقص یا انتشار عمومی فایل محافظت‌شده خودداری شده است.
- راهنمای تصویری 50 صفحه‌ای `zarpuls-user-guide-fa.pdf` در File Library وجود دارد و دانش ساختاری آن در `USER-GUIDE-SUMMARY-FA.md` منتقل شده است؛ بایت خام PDF از ابزار File Library این نشست قابل Export مستقیم نبود.
- `source-repo` به Repository عمومی `has5an-hash/zarpuls` متصل است، اما بررسی واقعی آن نشان داد در شاخه `main` فعلاً فقط دارایی `infographic.webp` قرار دارد؛ بنابراین این Submodule **سورس کامل افزونه نیست**.

## نکته مهم کاور و AI
در چت مرجع زرپالس، مالک تأکید کرده بود برای کارهای تصویری همان چت از GPT Image استفاده نشود. در هر صورت استاندارد زنده راست‌چین درباره تصاویر AI باید قبل از انتشار دوباره بررسی شود.

## قانون ادامه در Arena
برای تغییر کد زرپالس، ابتدا باید سورس واقعیِ قابل توسعه یا نسخه مرجعِ صریحاً اعلام‌شده در اختیار Arena قرار گیرد. فایل ionCube یا Readme به‌تنهایی جای سورس توسعه نیست.
