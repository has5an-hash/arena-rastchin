زرپالس نرخ‌های بازار را دریافت می‌کند، قیمت محصولات ووکامرس را با فرمول‌های قابل مدیریت محاسبه می‌کند و امکان رزرو زمان‌دار قیمت در سبد خرید را فراهم می‌سازد.

قابلیت‌های ثبت‌شده در مرجع readme:
- سه روش تامین نرخ: محاسبه هوشمند، نرخ اتحادیه و API مستقیم.
- فرمول‌ساز امن بدون اجرای کد دلخواه.
- نرخ پایه مستقل برای طلای ۱۸ عیار، ۲۴ عیار، مظنه، تمام‌سکه، نیم‌سکه و ربع‌سکه.
- قیمت‌گذاری اختصاصی هر محصول بر اساس وزن، عیار، اجرت، سود، مالیات و هزینه‌های جانبی.
- بروزرسانی دوره‌ای نرخ‌ها و قیمت محصولات با WP-Cron یا Cron واقعی سرور.
- رزرو زمان‌دار قیمت برای هر آیتم سبد خرید.
- کنترل فروش هنگام خطای بروزرسانی نرخ.
- شورت‌کدهای نمایش نرخ، گزارش‌ها، رابط مدیریت فارسی/RTL و HPOS اعلام‌شده.
