# فهرست محصولات و وضعیت مرجع

| محصول | نوع | مرجع اصلی | وضعیت انتقال |
|---|---|---|---|
| زرپالس / Zarpuls | افزونه WooCommerce طلا/جواهر | چت «وضعیت نهایی افزونه زرپالس» | اطلاعات و readme منتقل؛ سورس کامل خام در این نشست در دسترس نبود |
| بیوتیا / Beautia | قالب وردپرس زیبایی چنددمویی | چت «وضعیت نهایی قالب بیوتیا/تحویل از کامپیوتر» | Handoff/QA و سورس قابل استخراج منتقل؛ آرشیو خام همه هفت دمو در این نشست mount نبود |
| Loraniq Admin | قالب HTML مدیریت | چت «وضعیت نهایی قالب html لورانیک ادمین» | وضعیت و Build Spec منتقل؛ ZIP نهایی خام در این نشست mount نبود |
| آقای سئو | افزونه وردپرس سئو | چت «وضعیت نهایی افزونه آقای سئو» | هدف اولیه ثبت شده؛ توسعه/نسخه نهایی هنوز از این انتقال اثبات نشده |

هر محصول جدید باید یک پوشه مستقل زیر `10-PRODUCTS/` و حداقل `REFERENCE-STATUS-FA.md`, `CHECKPOINT`, `CHANGELOG`, `QA` و manifest خودش را داشته باشد.
