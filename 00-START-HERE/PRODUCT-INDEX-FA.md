## محصول جدید
برای ساخت محصول جدید از `20-NEW-PRODUCT-TEMPLATE/` شروع شود و پوشه مستقل زیر `10-PRODUCTS/` ساخته شود. حداقل Brief، Handoff/Checkpoint، Changelog، QA و Release Manifest نگهداری شود.

## نکته Submodule
برای دریافت سورس‌های لینک‌شده پس از Clone:

```bash
git submodule update --init --recursive
```

صرف جدید بودن تاریخ فایل به معنی جایگزین شدن مرجع قبلی نیست؛ Source of Truth و آخرین تصمیم معتبر همان محصول ملاک است.
