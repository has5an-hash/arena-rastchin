# فهرست محصولات و وضعیت مرجع

| محصول | نوع | مرجع اصلی | وضعیت انتقال |
|---|---|---|---|
| زرپالس / Zarpuls | افزونه WooCommerce طلا/جواهر | چت «وضعیت نهایی افزونه زرپالس» | اطلاعات و Readme منتقل؛ Repository عمومی موجود به‌صورت `source-repo` متصل است ولی سورس کامل افزونه بودن آن اثبات نشده |

| آقای سئو | افزونه وردپرس سئو | چت «وضعیت نهایی افزونه آقای سئو» | هدف اولیه ثبت شده؛ توسعه/نسخه نهایی هنوز از این انتقال اثبات نشده |

## محصول جدید
برای ساخت محصول جدید از `20-NEW-PRODUCT-TEMPLATE/` شروع شود و پوشه مستقل زیر `10-PRODUCTS/` ساخته شود. حداقل Brief، Handoff/Checkpoint، Changelog، QA و Release Manifest نگهداری شود.

## Repositoryهای خارجی
Loraniq Admin عمداً در `arena-rastchin` کپی نمی‌شود. منبع زنده آن فقط:

```text
https://github.com/has5an-hash/loraniq-admin
```

برای زرپالس، Submodule فعلی صرفاً Repository عمومی موجود را نشان می‌دهد و نباید بدون بررسی محتوای واقعی به‌عنوان سورس کامل فرض شود.

صرف جدید بودن تاریخ فایل به معنی جایگزین شدن مرجع قبلی نیست؛ Source of Truth و آخرین تصمیم معتبر همان محصول ملاک است.
