# ترتیب مراجع و Source of Truth

در صورت تعارض، اولویت اطلاعات این است:

1. قوانین الزام‌آور و به‌روز راست‌چین.
2. منابع رسمی و آموزشی راست‌چین در `02-RTL-THEME-OFFICIAL/`.
3. جدیدترین دستور صریح مالک در مرجع همان محصول، اگر با موارد بالا تعارض نداشته باشد.
4. جدیدترین تصمیم نهایی همان مرجع.
5. جدیدترین فایل/نسخه‌ای که صراحتاً «مرجع / نهایی / جایگزین» اعلام شده است.
6. اطلاعات قدیمی‌تر همان مرجع.
7. سایر گفتگوها و فایل‌های قدیمی.
8. دانش عمومی یا استنباط.

## مراجع محصولات

- زرپالس: چت `وضعیت نهایی افزونه زرپالس`.
- بیوتیا: چت `وضعیت نهایی قالب بیوتیا/تحویل از کامپیوتر`.
- آقای سئو: چت `وضعیت نهایی افزونه آقای سئو`.
- **لورانیک ادمین: مرجع زنده و منبع فایل‌ها فقط Repository مستقل زیر است:**
  `https://github.com/has5an-hash/loraniq-admin`

## استثناء قطعی لورانیک

برای Loraniq Admin هیچ کپی، ZIP، Build Spec، Snapshot یا Submodule داخل `arena-rastchin` منبع توسعه محسوب نمی‌شود. Arena باید مستقیماً Repository `has5an-hash/loraniq-admin` را Clone/Read کند و آخرین وضعیت معتبر همان Repository را مبنا بگیرد.

صرف جدید بودن تاریخ فایل به معنی جایگزین شدن مرجع قبلی نیست مگر این موضوع صریحاً اعلام شده باشد.
